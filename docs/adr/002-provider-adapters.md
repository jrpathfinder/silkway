# ADR-002: Внешние сервисы через адаптеры

## Решение

ЮKassa, Яндекс Еда, Яндекс Доставка, SMS/push и карты подключаются через интерфейсы портов. В development используются deterministic mock adapters.

## Причины

Коммерческий доступ, тарифы и доступные API могут меняться. Прямая привязка domain-кода к SDK провайдера усложнила бы тестирование, миграцию и fallback.
