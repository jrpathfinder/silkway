# Security и российский compliance baseline

Это инженерный чеклист для последующей проверки юристом и бухгалтером.

- [ ] Определить оператора ПДн и роли всех обработчиков.
- [ ] Подтвердить российский регион первичного хранения и обработки ПДн.
- [ ] Утвердить политику обработки ПДн, пользовательское соглашение, условия доставки/возврата.
- [ ] Версионировать согласия и отдельно хранить marketing opt-in.
- [ ] Реализовать экспорт/удаление профиля с учетом бухгалтерских сроков хранения заказов.
- [ ] Не хранить реквизиты банковских карт; использовать hosted checkout/tokenization PSP.
- [ ] Согласовать ККТ, ОФД, ставку НДС, предмет/способ расчета и электронные чеки по 54-ФЗ.
- [ ] Проверить договоры с SMS, push, hosting, maps, Yandex Eda и delivery providers.
- [ ] Ограничить доступ сотрудников RBAC, MFA для администраторов и audit log.
- [ ] Проверить retention, backup encryption, incident response и журнал webhook-событий.
- [ ] Провести threat modeling, dependency scanning и penetration test перед production.

По умолчанию OTP, биометрия, Госуслуги и трансграничная аналитика не включаются.
